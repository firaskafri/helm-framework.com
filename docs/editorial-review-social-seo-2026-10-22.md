## Findings and changes

- The production share card was generated by Sharp from SVG text that depended
  on system fonts. The Alpine Docker build installs no fonts. The screenshot's
  missing-letter boxes are consistent with this dependency.
- The renderer now outlines each glyph from bundled Inter WOFF files before
  rasterizing. Missing glyphs and remaining SVG text fail generation. The shared
  image is a real 1200×630 PNG, and the versioned URL avoids reusing the old image
  cache key. The old endpoint also generates corrected lettering.
- Social tags include matching titles, descriptions, HTTPS image URLs, image
  dimensions, PNG type, and useful alt text for Open Graph and Twitter cards.
  Canonical URLs remove trailing slashes consistently.
- Each indexable page declares linked WebSite, author, and WebPage entities with
  language, licensing, and editorial dates. Existing guide breadcrumbs remain.
  No ratings, guaranteed outcomes, or invented organization are added.
- The site uses locally bundled Inter fonts. No Google Fonts request is needed.
- The build derives Markdown from published HTML, including rendered MDX
  components. It retains examples, qualifications, tables, accordion names and
  symptoms, and links to source pages. Navigation and interface controls are
  removed. The public-content guard inspects the generated downloads after the
  Markdown integration. Noindex pages and browser fixtures receive no alternative.
- `/llms.txt` links all 20 indexable pages' Markdown alternatives and the public
  feeds. It states the framework's scope, example limitations, citation source,
  licensing, and the difference between current and planned resources.
- The reader-facing announcement is canonical in `src/data/updates.json`, with
  the generated release history and Updates RSS reflecting it.
